# Changelog

## [1.2.0] (2026-11-26)

### Added

- Open and preview 4 × 6 PDFs, and print each PDF page as a separate label.
- Add a Reconnect Printer button for the saved Bluetooth printer.

### Changed

- Retry the saved Bluetooth printer when opening or returning to Label Printer and when the Mac wakes.
- Send direct Bluetooth labels to the Nelko PL70e-BT using its compressed bitmap format.
- Explain how to open the GitHub download on macOS.

## [2026-11-25]

### Added

- Add a macOS disk image with a drag-to-Applications shortcut.
- Add a script to package and verify the release disk image.

### Changed

- Include the new icon in the v1.1.1 macOS release downloads.
- Use the supplied printer artwork for the macOS app icon.
- Show the disk image first in the installation instructions.
